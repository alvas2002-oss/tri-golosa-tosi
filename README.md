# Три голоса Тоси

Игровой урок русского языка для 2 класса: повествовательные, вопросительные и побудительные предложения. Кошка Тося объясняет правило на примере рыбки, показывает ловушку со знаками в конце, даёт тренировку и проверочную на 10 предложений. Реплики Тоси озвучены.

Открыть урок: https://alvas2002-oss.github.io/tri-golosa-tosi/

Это один статический HTML-файл и папка с аудио, без сборки и без сервера. `build.py` собирает эту копию из рабочего исходника.
